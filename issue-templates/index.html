Issue and Work Item Templates by Eolivion

Getting started

Issue and Work Item Templates by Eolivion fills in a work item from a template and creates its subtasks and child work items, in the order you set, with the links between them. It runs inside Jira and makes no calls to outside servers.

Set it up (Jira admin)

  1. Go to Settings > Apps > Issue and Work Item Templates.
  2. Under The Template field, tick the projects that should use templates and choose Create the Template field. The app creates a field called Template and adds it to those projects' create screens.
  3. Choose New template, or open a work item that's already set up the way you like and save it as a template (see below).

Team-managed projects don't share screens, so the app can't add the field there. People in those projects use Apply or save a template from the work item's ••• menu instead.

What a template holds

  • The work item itself: a description, labels and a priority. If someone already wrote a description, the template's goes below it. Labels are added, and the priority is only set if nobody picked one.
  • Items to create, in order: subtasks, and child work items for parents that can hold them, like an epic. Each one can have its own description, labels and priority.
  • Links between items: for example, "Kickoff call blocks Set up access".
  • Where it applies: the work types and projects that can use it. None ticked means all of them.

In the description, "## " makes a heading, "- " a list and "[ ] " a checkbox the team can tick off in Jira.

Use a template

When you create a work item: pick the template in the Template field and create it. A few seconds later the work item is filled in and its items are created under it.

The Template field only shows in the create window's full view. If your create window opens small, choose ••• > Full view once; Jira remembers it.

On a work item that already exists: open it, choose ••• > Apply or save a template, pick the template and choose Apply.

It also works when a work item is created by an automation rule or another tool, as long as the Template field is set.

Save a work item as a template

Open a work item, choose ••• > Apply or save a template and then Save this work item as a template. The app copies its description, labels, subtasks and child work items in their current order, and the links between them. Change anything before saving.

Jira admins can manage every template. Project admins can save and change templates that apply only to their own projects.

Order and reliability

Items are created one at a time, in the order of the template, each one already under its parent. If Jira asks the app to slow down, it waits and tries again instead of skipping the item. When it's done, the work item shows the result, for example "Release epic applied: 60 of 60 created", or which items failed and why.

Permissions and data

The app creates and edits work items itself, and sets the person who created the work item as the reporter of the new items. Before applying a template from the menu, it checks that the person can edit the work item and create work items in the project. Templates and the result of each run are kept in Atlassian's own storage for the app; see the privacy policy for exactly what's kept.
